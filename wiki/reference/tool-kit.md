# Master Tool Kit

Fixture-specific bits are listed on each fixture page under **Tools & screws**. When you confirm a screw size on a real fixture, add it to the page — that information is rarely in manuals.

## Hand tools
- [ ] Bit driver + bit set: **Torx T10, T15, T20, T25, T30**, **Phillips #1, #2**, flat 3/5/6 mm
- [ ] Metric hex: 1.5–8 mm (ball-end helps); SAE hex for US gear
- [ ] Adjustable (crescent) wrench, 8" — clamp bolts; a 3/4" / 19 mm combination wrench is also common for half-couplers ⚠️ check your clamps
- [ ] Ratchet and short sockets
- [ ] Needle-nose pliers, side cutters, zip-tie cutter
- [ ] Gobo tweezers/pliers, spare gobo springs and retainers
- [ ] Headlamp + flashlight (red mode for dark stages)
- [ ] Magnetic parts tray, pick-up magnet
- [ ] Inspection mirror

## Electrical & data
- [ ] Multimeter (with clamp-on amps for checking circuit load)
- [ ] Non-contact voltage tester, outlet tester (Edison)
- [ ] DMX tester/sniffer (Swisson XMT-350, DMXcat, Netron, etc.)
- [ ] DMX terminators: 5-pin **and** 3-pin
- [ ] 3↔5-pin adaptors, XLR barrels (F-F, M-M), phase-reverse adaptor
- [ ] Cable tester (XLR + RJ45)
- [ ] Spare TRUE1 cables and a TRUE1 to Edison
- [ ] etherCON barrel, short patch cables
- [ ] USB-to-DMX firmware interface for the brands you work on (see each maker's `_common` page)
- [ ] Laptop with fixture uploaders, manuals saved offline, sACN/Art-Net viewer

## Cleaning & maintenance
- [ ] Microfiber cloths, lens tissue
- [ ] Isopropyl alcohol (lenses — never on painted/coated plastics unless the manual allows)
- [ ] Electric blower or compressed air (hold fans still while blowing)
- [ ] Soft brush
- [ ] Nitrile gloves (handling discharge lamps — never touch the glass)

## Rigging
- [ ] Spare safety cables, spare omega bracket camlock fasteners, spare half-couplers / clamps
- [ ] Clamp bolts/nuts, lock washers
- [ ] Gloves, harness/lanyard per venue policy

## Consumables
- [ ] Gaff, spike tape, electrical tape
- [ ] Zip ties, velcro wraps
- [ ] Sharpies, labels
- [ ] Spare fuses for the fixtures you're running (type/rating on each fixture page)
- [ ] Spare lamps (discharge fixtures)
